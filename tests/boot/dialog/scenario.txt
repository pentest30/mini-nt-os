# ReactOS's kernel32 and user32): DIALOG1.EXE takes the place of
# winlogon.exe and, like taskmgr as the session shell, takes no desktop
# itself: its first window gets WinSta0\Default from the kernel, which gives
# that desktop the screen. CreateDialogIndirectParam makes a centred dialog
# (DS_SETFONT "MS Shell Dlg" 8, a static text, an OK button); user32 gives
# it its DIALOGINFO through SetDialogPointer (NtUserCallHwndParam 0x4F) and
# reads it back from the WND: without it, the dialog is destroyed as soon
# as made.
