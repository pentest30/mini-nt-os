# wined3d makes its hidden window (a class found from a null instance) and a

# pinned opengl32 are PFD_GENERIC_FORMAT, which wined3d refuses without
# WGL_ARB_pixel_format, and Direct3DCreate9 returns NULL. The next step needs
# a decision (an OpenGL ICD; see the doc). What win32k says of pixel formats,
# as ReactOS with a framebuffer driver: none described, none set or swapped.
