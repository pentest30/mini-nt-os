# M4, discovery: ReactOS's smss.exe starts under the system DLL with the
# parameters of the first process; the kernel logs the system services it
# calls and how it stops (docs/compat/m4-smss.md). It waits for csrss and
# winlogon, which it cannot start yet: the kernel ends it after 10 s.
# Skipped until the userland is fetched.

# creates its object directories and DOS device links (Ob), opens its
# KnownDlls directory on C: through Io, checks each KnownDLL in a view of a
# data section and makes its image section in \KnownDlls (Mm), writes its
# environment variables in the registry from the processor (Ex) and the
# HARDWARE hive (Cm), then finds csrss.exe, the Win32 subsystem it starts
# next, and cannot create the event csrss signals once connected (Ex, M5).
# Update with each step (docs/compat/m5-csrss.md).
