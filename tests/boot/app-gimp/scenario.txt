# M7 bench: GIMP 2.6.12 (Inno Setup), installed silently by APPBENCH.EXE
# (tests/native/appbench.c) from C:\APPS, then started and closed; the
# bench runs as the shell of the logged-on user (session).
# The markers say how far it goes; docs/compat/applications.md has the
# report.
features = test-smss, interactive
requires = userland, native
session = APPBENCH.EXE
boots = 2
app = gimp
cpus = default
timeout = 1500
# What works today, a floor: the loader extracts its setup.tmp
# (SetEndOfFile: FileAllocationInformation), which finds the user an
# administrator (CheckTokenMembership: NtAccessCheck), creates its
# temporary directory and runs its script; Inno Setup 5.4 then ends on
# STATUS_BAD_STACK (RtlUnwind), see docs/compat/applications.md.
# In the user's session, the failure of Inno 5.4 (its own code reads a
# heap page that Mino does not map; STATUS_STACK_OVERFLOW without a
# session) shows as Delphi's "Exception EAccessViolation" box, which
# waits: the bench ends the installer after its delay (install_seconds).
expect = [appbench] installer started
expect = Setup version: Inno Setup version 5.4.3
expect = User privileges: Administrative
expect = Created temporary directory:
expect = [appbench] installer ended: exit code
expect = [appbench] GIMP 2.6.12: report done
forbid = Unable to create a temporary file
forbid = User privileges: None
forbid = *** STOP:
