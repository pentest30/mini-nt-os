# report.

# What works today, a floor: the loader extracts its setup.tmp
# (SetEndOfFile: FileAllocationInformation), which finds the user an
# administrator (CheckTokenMembership: NtAccessCheck), creates its
# temporary directory and installs GIMP: its Delphi edit boxes over
# comctl32 6's Edit, a Unicode class asked in ANSI, get a call procedure
# (CALLPROCDATA, win32k::callproc; without it, Delphi's EAccessViolation box,
# the heap overwritten with UTF-16). Its log is longer than the bench's
# buffer: the bench prints its last lines only, not the Inno version.
# gimp-2.6.exe then opens its "GIMP Startup" window: EnumDisplayMonitors
# gives gdk the monitor (sys::monitor::nt_user_enum_display_monitors), its
# DLLs with long names are found (io::fat::FatVolume::add_entries), and
# SetThreadPriority works (NtSetInformationThread(ThreadBasePriority); before,
# GLib's fatal "Incorrect function" box). It queries its 150 plug-ins, one
# process each, then shows its Toolbox and image window 450 to 600 s later:
# the bench waits for another window than its first, up to 900 s
# (program_seconds in xtask/src/apps.rs), then it closes on WM_CLOSE. Its
# route then runs in batch mode (gimp-console, Script-Fu: ROUTE.BMP opened,
# blurred, exported as ROUTE.PNG, opened again: the pixel at the edge between
# black and white is gray), see docs/compat/applications.md.
