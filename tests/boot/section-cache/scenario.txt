# The sections of a file share what was read of it (io::section_cache), and
# a file is read in runs of sectors, an ATA command per run of 256 sectors
# (io::fat, io::disk): tests/native/section1.c (MinGW, ReactOS's kernel32)
# takes the place of winlogon.exe; C: is the ATA system disk. It writes
# 2 MiB to C:\SECTION.BIN and times three sections of it (NtCreateSection):
# the first reads the file, the second (the first still open) reads
# nothing, the third (both closed) reads it again. The times are logged,
# not judged, except that the second takes less than a tenth of the first.
features = test-smss, interactive
requires = userland, native
initial-command = SECTION1.EXE
disk     = system
cpus     = default, intel
timeout  = 180

expect = [boot] Io: system disk \Device\HarddiskVolume1 (ATA, secondary master, FAT32
expect = [section] C:\SECTION.BIN written: 2097152 bytes
expect = [section] first section: its bytes 1, in
expect = [section] second section, the first open: its bytes 1, in
expect = [section] the second took less than a tenth of the first: 1
expect = [section] both closed, a third: its bytes 1, in
# A write drops what the sections shared: a new section reads the file.
expect = [section] after a write at its start, a new section sees it: 1
# A section of \KnownDlls holds shell32.dll: its data section reads nothing.
expect = [section] shell32.dll as a data file: MZ 1, in
expect = [section] done

forbid = *** STOP:
forbid = [section] no view
forbid = [section] the write failed
