# The display settings (M6), from ReactOS's desktop: winlogon opens the
# session, userinit starts explorer (see the `logon` scenario); on its
# desktop, Win+R opens Run, and "control desk.cpl,,3" starts the Display
# panel on its Settings page (control.exe hands it to rundll32 shell32.dll,
# Control_RunDLL). QEMU then types Alt+S (the "Screen area" slider), Home (its
# smallest resolution, 640x480) and Enter (OK: ChangeDisplaySettingsEx with
# CDS_UPDATEREGISTRY), then Alt+Y in "Display Settings" (keep them). The
# panel ends; the screen stays 640x480 (a missed Alt+Y would go back to
# 1280x800 after 15 s, which is forbidden).
#
# The screen then, 640x480: explorer moved its taskbar to the bottom of the
# new screen on WM_DISPLAYCHANGE (its white top edge at y = 453, its face
# below, the Start button's light edge), and the desktop repainted above it
# (the change cleared the video memory: black otherwise).
#
# The panel's process is rundll32.exe, named in lower case after the path
# ShellExecute gave. `interactive`: the probe waits for smss for good (the
# reboot ends the first boot).
