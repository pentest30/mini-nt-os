# The icons (win32k::cursor; tests/native/icon1.c, MinGW, linked to ReactOS's
# kernel32 and user32): ICON1.EXE takes the place of winlogon.exe and
# switches to WinSta0\Default, which has user32 load the system cursors,
# then the 7 system icons (the callback SETWNDICONS); LoadIcon(NULL, IDI_*)
# finds them. Three windows with a caption and a system menu: A (40,100), of
# a class without an icon, shows the system's small IDI_WINLOGO; B
# (450,100), of a class whose icon is IDI_HAND, shows it, and draws it at
# 32 x 32 in its client area with DrawIconEx; C (860,100), given IDI_ASTERISK
# by WM_SETICON, shows it.

expect = [icon] WM_SETICON(ICON_SMALL): none before 1; WM_GETICON gives it 1, no big one 1
