# The Save As dialog of ReactOS's Notepad (tests/native/notepad3.c):
# comdlg32 with shell32's file view of C:\, filtered on *.txt: three folders
# (Documents and Settings, MINODIR, WINDOWS) and two text files, with their
# icons. shell32's icon cache (SIC_Initialize) puts IDI_SHELL_DOCUMENT in
# comctl32's image lists: CopyImage(LR_COPYFROMRESOURCE) asks
# NtUserGetIconInfo for the icon's module and resource, ImageList_ReplaceIcon
# GetIconInfo for copies of its bitmaps, which it reads by GetDIBits
# (add_with_alpha); without them the cache failed and shell32 retried forever.
# The view asks its ListView's header for its column count before the header
# exists: SendMessage to no window must give 0 (it gave user32's
# uninitialised variable, and CDefView asserted). The view's
# NtUserGetAtomName of its class atom must stay in the caller's buffer (it
# overwrote the stack).
#
# The probe first registers shell32 (DllRegisterServer), as minoinit.exe does
# at the end of the installation: its scripts (REGISTRY resources) write the
# CLSIDs of the shell's folders under HKCR, whose DefaultIcon the places bar
# reads (CGuidItemExtractIcon_CreateInstance; without them, the blank paper
# of IDI_SHELL_DOCUMENT). advapi32 asks the name of each key it creates under
# HKCR (NtQueryKey, KeyNameInformation) by a handle without KEY_QUERY_VALUE:
# any access must do (it gave STATUS_ACCESS_DENIED, and the registration
# failed). The registration also creates the user's shell folders, so the
# dialog opens in My Documents, empty; typing C:\ in the file name goes to
# the root.
