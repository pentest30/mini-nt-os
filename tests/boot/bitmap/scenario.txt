# M5, console (docs/compat/m5-console.md, step 5): BITMAP1.EXE
# (tests/native/bitmap1.c, MinGW, linked to ReactOS's kernel32, user32 and
# gdi32) takes the place of winlogon.exe, which smss starts as its initial
# command once csrss runs. Like winlogon, it takes WinSta0\Default and opens
# a window; in its WM_PAINT, what consrv paints its console with:
# - GetDeviceCaps reads the display's capabilities in the shared GDI table
#   (DC_PRIMARY_DISPLAY), for a window's DC and for a memory DC;
# - CreateCompatibleDC, CreateSolidBrush, CreateDIBSection (32 bits per
#   pixel, from the top row down): the pixels are in a section that the
#   program sees at the address CreateDIBSection gives it, and the kernel
#   by a system view;
# - SelectObject of the DIB gives back the default bitmap; PatBlt with the
#   brush into the DIB: the program reads the brush's pixel;
# - the program writes a red pixel, BitBlt copies the DIB to the window (the
#   kernel reads it), BitBlt copies that within the window (a scroll), then
#   from the window into a second DIB, where the program reads it;
# - a bottom-up DIB: its top row is the last in memory;
# - a bitmap goes in one DC at a time; DeleteObject of a selected bitmap
#   fails; once out of the DC, the bitmaps, the brush (whose deletion gdi32
#   queues) and the memory DC go, and the DIB's pixels leave the program's
#   memory;
# - what comctl32's image lists and toolbar ask: StretchBlt between DIB
#   sections, larger (each source pixel twice) then smaller (every other
#   one); GetNearestColor (the colour itself on 32 bits); GetDIBits of a
#   bitmap of 32 bits (its format alone: BI_BITFIELDS as ReactOS; its lines
#   from the top, then from the bottom) and of a monochrome one (black and
#   white, its bottom line first); StretchDIBits of a 16-bit DIB with its
#   5-6-5 masks (BI_BITFIELDS, as comctl32's toolbar bitmaps, of 32 bits);
# - what its toolbar, its image lists of 4 bits and alpha icons ask: BitBlt
#   from colours to a monochrome bitmap (the source's background colour
#   gives white) and back (black: the destination's text colour, white: its
#   background colour); a DIB section of 4 bits (painted near red: the index
#   of red in its table; GetObject; GetDIBits of 4 bits: its table, or the
#   VGA one, silver before gray); CreateDIBitmap keeping the alpha;
#   GdiAlphaBlend with each pixel's alpha (0x40 premultiplied over 0xC8 at
#   0x80: 0xA3).
features = test-smss
requires = userland, native
initial-command = BITMAP1.EXE
cpus     = default, intel
timeout  = 120

expect = [bitmap] on WinSta0\Default
expect = [bitmap] GetDeviceCaps: 1280x800, 32 bits, 1 plane, -1 colours, 96 dpi, BitBlt yes; memory DC 32 bits
expect = [bitmap] CreateCompatibleDC: a DC, CreateSolidBrush: a brush, CreateDIBSection: a bitmap, bits mapped
expect = [bitmap] SelectObject: the old bitmap is the default bitmap
expect = [bitmap] SelectObject in a second DC: refused; the pixels: mapped, type 7
expect = [bitmap] GetObjectW: DIBSECTION 84, 16x8, 64 bytes a row, 32 bits, pixels its own, header 40 16 8 32, image 512
expect = [bitmap] GetObjectW: BITMAP 24, pixels its own; a monochrome one 24, 2 bytes a row, 1 bit, pixels none
forbid = NtGdiExtGetObjectW (0x1090) is not implemented
expect = [bitmap] PatBlt: 1, pixel 00123456
expect = [bitmap] BitBlt to the window: 1; within it: 1
expect = [bitmap] BitBlt from the window: 1, pixels 00123456 00ff0000
expect = [bitmap] SelectObject again: the old bitmap is the first DIB; DeleteObject of the selected one: 0
expect = [bitmap] bottom-up: the top row last, the first in memory untouched
expect = [bitmap] DeleteObject: 1 1 1, DeleteDC: 1
expect = [bitmap] deleted: the pixels free, types 0 0 0
expect = [bitmap] painted: yes
expect = [bitmap] StretchBlt 2x1 to 4x2: 1, 00ff0000 00ff0000 00123456 00123456, 00ff0000 00123456
expect = [bitmap] StretchBlt 4x2 to 2x1: 1, 0000ff00 000000ff
expect = [bitmap] GetNearestColor: 00030201; of no DC: CLR_INVALID
expect = [bitmap] GetDIBits of a bitmap of 32 bits, its format: 2, 4x2, 32 bits, compression 3, 32 bytes
expect = [bitmap] GetDIBits from the top: 2, 00ff0000 00123456, then 00000001
expect = [bitmap] GetDIBits from the bottom: 2, 00000001, then 00ff0000
expect = [bitmap] GetDIBits of a monochrome bitmap: 2, colours 000000 ffffff, rows 00ff a50f
expect = [bitmap] StretchDIBits of 5-6-5 bit fields: 1, pixel 0000ff00
expect = [bitmap] BitBlt to monochrome: 80; back to colours: 0000ff00 000000ff
expect = [bitmap] a DIB section of 4 bits: 4 bits, 16 colours; painted near red: 10; GetDIBits: 10, its red ff0000
expect = [bitmap] the default table of 4 bits: c0c0c0 808080 ff0000
expect = [bitmap] CreateDIBitmap of 32 bits: a bitmap, read back 80402010
expect = [bitmap] GdiAlphaBlend: 1, 80a3a3a3 00c8c8c8
expect = [bitmap] done
forbid = *** STOP:
forbid = sys: NtGdiCreateCompatibleDC (0x101e) is not implemented
forbid = sys: NtGdiCreateDIBSection (0x1021) is not implemented
forbid = sys: NtGdiSelectBitmap (0x1100) is not implemented
forbid = sys: NtGdiBitBlt (0x100d) is not implemented
forbid = sys: NtGdiCreateSolidBrush (0x102c) is not implemented
forbid = sys: NtGdiStretchBlt (0x1123) is not implemented
forbid = sys: NtGdiGetDIBitsInternal (0x10ad) is not implemented
forbid = sys: NtGdiGetNearestColor (0x10b9) is not implemented
forbid = sys: NtGdiAlphaBlend (0x1007) is not implemented
