# (tests/native/appbench.c) from C:\APPS, then started and closed; the
# bench runs as the shell of the logged-on user (session).
# The markers say how far it goes; docs/compat/applications.md has the
# report.

# What works today, a floor: it installs, and in the user's session its
# window opens and closes with 0. Its route then goes through its windows
# (route-step in xtask/src/apps.rs): a line typed (the title gets its
# `*`), all of it put in bold (Ctrl+A, Ctrl+B), Ctrl+S opens the Save
# File As dialog, the name typed and the type list jumped to its `r` entry
# (Rich Text Format), the file written in My Documents (AbiWord's default
# folder), opened again on that file, and its text copied to the clipboard
# for the probe to read. It does not close on WM_CLOSE in 15 s (like
# KeePass's window): the bench terminates it.

expect = [appbench] route step: rtf written

# The route's keys: a line typed in the untitled document, all of it put in
# bold (Ctrl+A, Ctrl+B), Ctrl+S opens the Save As dialog (a document
# without name); there, the file name (Alt+N) then the type list (Alt+T)
# walked to Rich Text Format, Enter saves.
