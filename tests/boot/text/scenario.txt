# M6, text: TEXT1.EXE (tests/native/text1.c, MinGW, linked to ReactOS's
# kernel32, user32 and gdi32) takes the place of winlogon.exe, like GUI1.EXE
# in `gui`. It takes a desktop like winlogon, then works with GDI's text
# (win32k::gdi::fontobj, win32k::gdi::text, ADR-013):
# - GetStockObject gives fonts (NtGdiGetStockObject: OBJ_FONT, public), and
#   a new DC's font is the system font (hlfntNew of its attributes);
# - CreateFontW (NtGdiHfontCreate) a font of the process;
# - GetTextMetricsW (NtGdiGetTextMetricsW) the metrics of the default GUI
#   font (MS Shell Dlg, -11, given Tahoma): XP's for Tahoma 8 points;
# - GetTextExtentPoint32W (NtGdiGetTextExtent) the width of a text, larger
#   in bold, and the font's height;
# - its window paints, in WM_PAINT, through gdi32 and LPK (whose TextOut and
#   SelectObject are queued in the TEB, GdiBCTextOut and GdiBCSelObj): "Mino"
#   in navy, transparent, at 10, 10 of its client area (303, 223 on the
#   screen); "Opaque text" on yellow (OPAQUE, ETO_OPAQUE | ETO_CLIPPED) cut
#   to its rectangle from 10, 40 to 60, 60; "Bold" in a font of its own.
# It ends with status 0x600D.
# Update with each step (docs/compat/m6-fenetres.md).
features = test-smss
requires = userland, native
initial-command = TEXT1.EXE
cpus     = default, intel
timeout  = 120

expect = [boot] fonts installed: tahoma.ttf, tahomabd.ttf, Marlett.ttf
expect = [text] on WinSta0\Default
expect = [text] GetStockObject: DEFAULT_GUI_FONT a font (type 6), SYSTEM_FONT a font (type 6)
expect = [text] TextOutW: 1
expect = [text] ExtTextOutW, opaque and clipped: 1
expect = [text] TextOutW, bold: 1
expect = [text] painted: yes
expect = [text] SelectObject: the old font is the system font
expect = [text] GetTextMetricsW: height 13, ascent 11, descent 2, internal 2, external 0, average 5, maximum 15, weight 400, chars 0020-fefc, pitch 27, charset 0
expect = [text] CreateFontW: a font (type 6)
expect = [text] GetTextExtentPoint32W(Mino): 23 x 13, bold 27 x 13
expect = [text] done
expect = [m4] SMSS.EXE created winlogon.exe (PID 28): exit status 0x0000600d
