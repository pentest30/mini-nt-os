# procedure (CALLPROCDATA, win32k::callproc; without it, the control wrote
# UTF-16 into the Delphi heap, and setup.tmp ended on STATUS_STACK_OVERFLOW).
# It copies its files, then cannot create one in a directory with a long
# name of 18 characters (nographic-embedded: the entry has no long name,
# "The system cannot find the path specified") and rolls back, see
# docs/compat/applications.md.
