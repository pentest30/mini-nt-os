# The desktop starts programs from its Start menu: Terminal by the keyboard
# (Down twice to it, Enter), ReactOS's cmd.exe in a console of its own; then,
# with the mouse, the Start button opens the menu again and a press on Task
# Manager starts taskmgr.exe, which reads the process list.
#
# The pointer starts at the centre of the 1280x800 screen (640,400); moves are
# split, QEMU's PS/2 queue holding 16 bytes.
#
# Once Task Manager has read the list, the mouse closes it (its close button)
# and starts it again from the Start menu: it saved its place
# (GetWindowPlacement; without it, bytes of its stack, and the second window
# was nowhere to be seen). In the second one, a press on Processes, then on
# Applications, waits between steps (moves of nothing) leaving time to paint.
#
# The screen then: cmd's console (black, at the top left) is still over the
# desktop, which a press on the Start button activates without bringing it
# over the windows it started; the taskbar. Task Manager's Applications page
# over its tab control, which erases all its inside (COLOR_BTNFACE) and has no
# WS_CLIPSIBLINGS: the first row of the list selected, the underlined N of New
# Task..., the white relief under the S of Switch To and the E of End Task,
# disabled (DrawState, a font from GetObjectW). Siblings repaint from the
# bottom of the Z order up; from the top, the tab control painted over the
# page, gray.
