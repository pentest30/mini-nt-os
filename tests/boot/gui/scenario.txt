# M6, windows: GUI1.EXE (tests/native/gui1.c, MinGW, linked to ReactOS's
# kernel32 and user32) takes the place of winlogon.exe, which smss starts as
# its initial command once csrss runs. Like winlogon, it registers as the
# logon process, creates WinSta0 and a desktop and goes on it; then it
# registers a window class (user32 registers its system controls first),
# finds it and user32's Button again (GetClassInfoExW), cannot find a class
# never registered nor register its own twice. It creates a window of its
# class: its procedure receives WM_NCCREATE and WM_CREATE (the CREATESTRUCT
# as given; meanwhile the TEB's CLIENTINFO names the window and its WND),
# WM_NCCALCSIZE, WM_SIZE and WM_MOVE, through KeUserModeCallback;
# user32 reads by itself its name, style and rectangle in its WND; its name
# changes (SetWindowTextW: WM_SETTEXT, NtUserDefSetText). A child window
# tells its parent (WM_PARENTNOTIFY), which user32 finds through the WNDs'
# links. A child without a parent, a window of no class and one whose
# procedure refuses WM_NCCREATE are not created. The kernel part of
# DefWindowProc (NtUserMessageCall) is not there yet. It ends with status
# 0x600D.
# Update with each step (docs/compat/m6-fenetres.md).
