# M5, console (docs/compat/m5-console.md): CONSOLE1.EXE
# (tests/native/console1.c, MinGW, linked to ReactOS's kernel32 and user32)
# takes the place of winlogon.exe, which smss starts as its initial command
# once csrss runs. Like winlogon, it takes WinSta0\Default; then it starts
# THREADS1.EXE (tests/native/threads1.c), a program of the CONSOLE
# subsystem, by CreateProcessW, and waits for it:
# - kernel32 creates the process (NtCreateProcessEx, which gives the new PEB
#   in the creator's TEB, NtTib.ArbitraryUserPointer, as ReactOS's kernel
#   does), writes its parameters, creates its thread and tells basesrv;
# - in the new process, kernel32 asks consrv for a console: csrsrv
#   impersonates the client thread (NtImpersonateThread, then
#   NtSetInformationThread(ThreadImpersonationToken, NULL)), consrv
#   resolves its desktop (NtUserResolveDesktop), starts the console input
#   thread of that desktop (NtUserConsoleControl) and creates the console
#   window, with the console's font: VGA (UniVGA16.ttf), which
#   EnumFontFamiliesExW finds (NtGdiGetFontFamilyInfo) fixed-pitch and
#   FF_MODERN, as IsValidConsoleFont2 asks;
# - THREADS1.EXE runs: 8 threads add to a counter under a critical section
#   (16000 in all, never two in it at once), then it writes to its console
#   (WriteConsoleW) and ends with 0x600D, which CONSOLE1.EXE reads.
# Sleep(0) does not yet give the processor up (Ke): the threads do not wait
# for the critical section ("contended: no"), see docs/compat/m5-console.md.
# Update with each step (docs/compat/m5-console.md).
features = test-smss
requires = userland, native
initial-command = CONSOLE1.EXE
cpus     = default, intel
timeout  = 120

expect = [console] on WinSta0\Default
expect = [console] CreateProcessW: a process and its thread
expect = [threads] started
expect = [threads] EnterCriticalSection twice: recursion 2
expect = [threads] 8 threads: wait 0, counter 16000 of 16000, overlaps 0
expect = [threads] WriteConsoleW: 1 (0), 17 characters
expect = [console] THREADS1.EXE: wait 0, exit code 600d
expect = [console] done
expect = [boot] SOFTWARE hive mounted at \REGISTRY\MACHINE\SOFTWARE
