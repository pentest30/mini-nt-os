# SendMessage between threads (win32k::sent; tests/native/send1.c, MinGW,
# linked to ReactOS's kernel32 and user32): SEND1.EXE takes the place of
# winlogon.exe, takes WinSta0\Default, opens window W in its main thread,
# then starts a worker thread, which opens window V and sends to W. user32
# goes through NtUserMessageCall (FNID_SENDMESSAGE, FNID_SENDMESSAGEWTOOPTION,
# FNID_SENDNOTIFYMESSAGE); win32k puts the message among the sent messages of
# W's thread (QS_SENDMESSAGE), whose GetMessage runs W's procedure without
# returning the message, and the value goes back to the worker:
# - W's procedure runs in the main thread: 5 + 10 x 7 = 75;
# - a pointer to the worker's stack in lParam (one process): written;
# - nested: while W handles WM_USER + 3, the main thread sends to V; the
#   worker, waiting for W, runs V's procedure meanwhile: 300 + 4;
# - SendMessageTimeout of 100 ms to a procedure that sleeps 400 ms: FALSE,
#   ERROR_TIMEOUT (1460); then one of 5 s: TRUE and 1 + 10 x 2;
# - SendNotifyMessage: TRUE at once, handled by the main thread;
# - WaitMessage (Codex's review of #84): a message sent while the main thread
#   waits in it is handled during the wait, which a later posted message
#   ends;
# - a thread that ends without answering: SendMessage to its window fails in
#   about a second, though a third thread posts to the sender every 50 ms
#   (the recipient's liveness is looked at whatever wakes the sender);
# then the worker posts WM_QUIT.
features = test-smss
requires = userland, native
initial-command = SEND1.EXE
cpus     = default, intel
timeout  = 120

expect = [send] ready
expect = [send] worker ready: V created
expect = [send] W got 401 in the main thread
expect = [send] SendMessage to the main thread: 75
expect = [send] through a pointer: 1, written 1234
expect = [send] V got the nested message in the worker thread
expect = [send] nested: 304
expect = [send] SendMessageTimeout of 100 ms: 0, error 1460
expect = [send] SendMessageTimeout of 5 s: 1, result 21
expect = [send] SendNotifyMessage: 1
expect = [send] W got the notification in the main thread
# A kernel buffer to another thread (M5, step 26): the WINDOWPOS of
# WM_WINDOWPOSCHANGING goes to W's thread as a copy, and what W's
# procedure writes in it comes back (150 wide, not 123).
expect = [send] SetWindowPos of W from the worker: 1; W got WM_WINDOWPOSCHANGING in the main thread 1, width 123; W is 150 wide
forbid = with a kernel buffer sent to another thread: not yet
expect = [send] sent during WaitMessage: 7
expect = [send] WaitMessage returned; the sent message handled during it 1
expect = [send] SendMessage to a thread that ended: 0, under 2 s 1
expect = [send] sent messages out of GetMessage: 0; notified 1
expect = [send] done
expect = exit status 0x00007002
