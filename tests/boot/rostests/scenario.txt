# Le dernier critère du M5 : les apitests de ReactOS (ntdll ici, kernel32
# dans `rostests-kernel32`) dépassent le seuil de réussite du jalon. Les
# bancs sont construits par `rostests-build` (modules/rostests/apitests de
# l'arbre 0.4.16 que clone `rostests-fetch`, le SDK recopié et le winnt.h
# généré, la SAL neutralisée, PSEH en statique) ; sans l'arbre, le scénario
# est sauté. NTAPITST.EXE, le pilote, démarre comme commande initiale à la
# place de winlogon : il prend WinSta0\Default comme lui, puis lance chaque
# test dans un coureur détaché (C:\NTAPIRUN.EXE <test>) et relaie sa sortie
# et son verdict par DbgPrint :
#   [apitest] | <ligne de la sortie du test>
#   [apitest] <test>: pass | FAIL (exit N) | FAIL (timeout) | no-process=N
#   [apitest] TOTALS: tests=N failures=N skipped=0
# L'hôte juge le bilan (xtask/src/rostests.rs) : au moins `apitests-floor`
# tests passent (ceux de la dernière mesure : le plancher ne baisse pas) ;
# la part qui passe est comparée au seuil du M5 (THRESHOLD, 0,50) et
# rapportée. `interactive` : la sonde de smss attend le pilote sans délai ;
# sans lui, elle termine smss et ses processus 10 s après leur début, au
# milieu du banc.
features = test-smss, interactive
requires = userland, native, rostests
initial-command = NTAPITST.EXE
apitests-floor = 43
cpus     = default
timeout  = 900

expect = [apitest] begin
expect = [apitest] TOTALS: tests=

# Un banc qui meurt avant son bilan (AV, DLL manquante) ne passe pas.
forbid = *** STOP:
