# M6, the logon (ADR-023, docs/compat/m5-csrss.md step 27, docs/compat/m6-logon.md).
# The hives of the boot disk carry the Mino layer (tools/mkhive/mino.inf):
# the first boot is in setup mode, the second goes to the logon. Two boots
# on the system disk, so that what the first writes (the hives, the
# profiles) is there for the second.
#
# First boot: samsrv makes the accounts (setup mode), winlogon starts
# MINOINIT.EXE (SYSTEM\Setup\CmdLine), which waits for Administrator in
# the SAM, makes the profiles (userenv's InitializeProfiles: C:\Documents
# and Settings, a long-named directory), copies HKU\.DEFAULT, written back,
# as NTUSER.DAT of Default User, sets SetupType = 0, writes the hives back
# and reboots. Every step logs "[minoinit] ..."; a failed step stops it
# ("[minoinit] stopped: ..."). It also logs its environment: smss passes on
# SystemDrive, which the kernel gives it as ReactOS's does.
#
# Second boot: winlogon goes to the logon, msgina logs Administrator on
# (AutoAdminLogon) through LsaLogonUser; msv1_0 finds the account and its
# blank password in the SAM, and lsasrv makes the user's token
# (NtCreateToken). winlogon makes the profile of Administrator from Default
# User (CopyFileW asks FileEaInformation), loads and unloads its NTUSER.DAT
# (NtLoadKey, NtUnloadKey), then loads it for the session in
# \REGISTRY\USER\<SID>; impersonates the user (NtDuplicateToken), sets the
# user's locale from the profile (Control Panel\International\Locale, from
# the Mino layer; NtSetDefaultLocale) and is logged on. msgina starts
# userinit.exe under the user's token (CreateProcessAsUser:
# NtSetInformationProcess, ProcessAccessToken, with a token copy of the same
# access); userinit sets the user up and starts the shell,
# C:\WINDOWS\explorer.exe (xtask puts the programs of the Windows directory
# on the disk, with their imports), whose thread win32k converts. Where the
# logon stops today: explorer raises an exception in its first steps
# (docs/compat/m6-logon.md, « explorer »).
#
# `interactive`: the probe waits for smss for good (the reboot ends the
# first boot); without it, it would end smss 10 s after its start.
features = test-smss, interactive
requires = userland, native
disk = system
boots = 2
cpus = default
timeout = 300

expect = [boot] .DEFAULT hive mounted at \REGISTRY\USER\.DEFAULT
expect = [minoinit] environment: SystemDrive=C:
expect = [minoinit] done; rebooting
expect = IncrementRefCount(S-1-5-21-
expect = We are logged on
expect = of userinit.exe
expect = of explorer.exe

forbid = [minoinit] stopped:
forbid = *** STOP:
forbid = NtCreateToken failed
forbid = LsaLogonUser failed
forbid = CreateUserProfileW() failed
forbid = RegLoadKeyW() failed
forbid = ImpersonateLoggedOnUser() failed
forbid = Failed to assign primary token
forbid = CreateProcessAsUserW() failed
forbid = Failed to start default shell
