# What works today, a floor: msiexec installs it in C:\Program Files
# (NtLockFile for ole32's structured storage, CreateDirectoryW of
# C:\WINDOWS\Installer\, ProgramFilesDir in mino.inf), and its file
# manager opens and closes. Its route then runs by its command line, a batch
# file under cmd.exe (C:\APPS\ROUTE.CMD, written by xtask with ROUTE.TXT):
# 7z.exe archives ROUTE.TXT, tests ROUTE.7Z, extracts it in C:\APPS\OUT, and
# fc /b finds the extracted file the same; each failed step ends cmd.exe
# with its own code (exit 1 to exit 4: ReactOS's cmd does not pass on the
# code of exit /b).
